# Roles and Permissions

## Administrator

Gestiona plataforma.

## Process Architect

Diseña procesos.

## Process Owner

Responsable funcional.

## Supervisor

Supervisa ejecución.

## Participant

Ejecuta tareas.

## Viewer

Consulta.

## Principio

Authorization siempre se valida backend-side.

Frontend permissions son únicamente UX.
