# Demo Process

Proceso:

Solicitud de compra

## Flujo

```text
START
↓
Registrar solicitud
↓
Revisión del supervisor
↓
Decision
```

Si aprobado:

```text
Aprobación administrativa
↓
END
```

Si rechazado:

```text
END
```

## SLA

- Registrar: 4 horas.
- Supervisor: 1 día.
- Administrativo: 2 días.

## Objetivo

Este proceso será utilizado para:

- development
- seed data
- integration testing
- E2E testing
- demos
