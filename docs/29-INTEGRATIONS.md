# Integrations

Architecture should support future integrations.

## Communication

- Webhooks
- REST APIs

## Messaging

- Email
- WhatsApp
- SMS

## Documents

- Electronic signature
- Google Drive
- OneDrive

## Identity

- Google
- Microsoft
- LDAP
- SSO

## Enterprise

- ERP
- CRM
- Accounting

## Rule

Integrations must not be tightly coupled to Process Engine.

Use adapters/events.
