# Acceptance Criteria

El MVP será aceptable cuando sea posible:

1. Crear usuario.
2. Crear organización.
3. Crear proceso.
4. Abrir diseñador.
5. Agregar Start.
6. Agregar Human Task.
7. Agregar Approval.
8. Agregar End.
9. Conectarlos.
10. Configurar responsable.
11. Configurar SLA.
12. Guardar draft.
13. Validar.
14. Publicar.
15. Crear instancia.
16. Crear automáticamente primera tarea.
17. Mostrarla en inbox.
18. Completarla.
19. Avanzar al siguiente nodo.
20. Aprobar.
21. Finalizar instancia.
22. Consultar timeline.
23. Consultar auditoría.
24. Adjuntar documento.
25. Confirmar que una nueva versión no afecta la instancia anterior.
