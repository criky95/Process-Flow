# Product Requirements Document

## Objetivo

Permitir diseñar, publicar y ejecutar procesos.

## MVP

El sistema debe permitir:

1. iniciar sesión;
2. crear organización;
3. crear proceso;
4. diseñarlo visualmente;
5. configurar tareas;
6. asignar responsables;
7. configurar tiempos;
8. publicar versión;
9. iniciar instancia;
10. asignar tareas;
11. completar tareas;
12. avanzar automáticamente;
13. adjuntar documentos;
14. completar formularios;
15. visualizar timeline;
16. auditar eventos;
17. consultar estado.

## Perfiles

- Administrator
- Process Architect
- Process Owner
- Supervisor
- Participant
- Viewer

## Fuera del MVP

- IA avanzada
- simulación
- process mining
- firma electrónica avanzada
- marketplace
- automatización RPA
