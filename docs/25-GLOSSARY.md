# Glossary

**Process Definition:**  
Plantilla lógica.

**Process Version:**  
Snapshot publicado.

**Process Instance:**  
Ejecución real.

**Task Definition:**  
Actividad dentro del diseño.

**Task Instance:**  
Actividad real asignada.

**Case:**  
Nombre de negocio para una Process Instance.

**Process Architect:**  
Diseñador del proceso.

**Participant:**  
Usuario que ejecuta tareas.

**SLA:**  
Tiempo comprometido.

**Escalation:**  
Acción producida por incumplimiento o proximidad de SLA.
