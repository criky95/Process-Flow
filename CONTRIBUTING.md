# Contributing

## Branches

- feature/*
- fix/*
- refactor/*
- docs/*

## Before pull request

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

## Commit style

- feat:
- fix:
- refactor:
- test:
- docs:
- chore:

## Architecture

Large architectural changes require ADR.

## Documentation

When behavior changes, update the corresponding `/docs` file.
